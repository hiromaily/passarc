> **Note (after implementation):** this is the plan as written before implementation, kept as a record and
> translated to English. Implementation departed from it in these ways (details in the design's
> "Revision history" and in `docs/development-notes.md`):
> - Xcode could not be installed, so XcodeGen / `xcodebuild` / `project.yml` were replaced by `scripts/build.sh`
>   (`swiftc`, ad-hoc signing, `pluginkit`), and the app is installed to `~/Applications`.
> - `7zz t` is run without `-p` (a bare `-p` means an empty password on `t`), with `-bb1 -bsp0 -spd`, and files are
>   counted from its `T <name>` lines. `-bso0` was dropped from the create command (it hid the password prompt).
> - `-spd` was added; excludes moved to a list file (`-scsUTF-8 -xr@<file>`), filled from `FileInventory`, which now
>   walks the tree with `readdir`/`lstat`.
> - The UI is in English; the password fields are `NSSecureTextField` and the format radios are `NSButton`.
> - Final-review fixes: single files, SIGPIPE, items from different folders, `@` names for tar, parallel jobs,
>   passwords over 1024 characters, no password masking in error text.

**Goal:** Build PassArc, a macOS app that compresses to 7z / ZIP (AES-256) / tar.zst from "Archive with Password"
at the top level of the Finder context menu.

**Architecture:** The compression rules and logic live in the Swift package `PassArcCore` (Foundation only) and are
tested with `swift test`. The app (AppKit + SwiftUI, not sandboxed, `LSUIElement`) shows the dialog and compresses.
The Finder Sync extension (sandboxed) only shows the menu and opens the app with `passarc://archive?...`. The Xcode
project is generated from XcodeGen's `project.yml`.

**Tech Stack:** Swift 6 / Swift Testing / SwiftUI and AppKit / FinderSync / UserNotifications / XcodeGen / 7-Zip
`7zz` (Homebrew `sevenzip`) / `/usr/bin/tar` / `zstd`

**Spec:** `poc/passarc/docs/superpowers/specs/2026-11-08-passarc-design.md` (read it together with this plan)

## Global Constraints

- Location: `poc/passarc/`. vehicle-location-map's skills, rules and checks (Biome, cc-sdd, lefthook, ...) do not
  apply. Do not change files tracked by vehicle-location-map.
- git: a separate repository created with `git init` inside `poc/passarc/`. Nothing is committed to
  vehicle-location-map. `poc/.superpowers/` is not committed anywhere.
- Write every command with absolute paths and no `cd` (git: `git -C /Users/hiroki.yasui_824054/work/workspace2/vehicle-location-map/poc/passarc`, swift: `--package-path`).
- Target macOS 15 or later, Apple Silicon. Swift 6 language mode.
- The menu item is English: `Archive with Password`. Dialog text is Japanese (changed to English on 2026-11-08;
  design §2).
- Three formats: 7z / ZIP / tar.zst. No descriptions such as "security first".
- Levels: Fast / Normal / Maximum. `-mx` 1 / 5 / 9, zstd `-1` / `-3` / `-19`.
- 7z uses `-mhe=on`, ZIP uses `-tzip -mem=AES256`. Multithreading on. Never ZipCrypto.
- **Never put the password in process arguments, logs, `UserDefaults` or error text.** It reaches 7zz by answering
  the "Enter password" prompt through a pseudo-terminal.
- A password must not be empty, must match the confirmation, and may contain only printable ASCII (U+0020–U+007E).
- Never delete or modify the original files. Never overwrite output.
- Look up 7zz and zstd in `/opt/homebrew/bin`, then `/usr/local/bin`. tar is `/usr/bin/tar`.
- Leave out `.DS_Store` and `._*`. tar runs with `COPYFILE_DISABLE=1`. Store symbolic links as links.

## Review Focus

1. **Names starting with `-`, or containing spaces or Japanese** (`-report`, `売上 2026`): 7zz must not take them
   for switches and must store them as is → Task 4 `sevenZipArguments_putsDoubleDashBeforePaths` and Task 6
   `job_handlesDashAndJapaneseNames`
2. **Passwords with characters special to a terminal** (`a b"'\$!` with spaces, quotes, `\`, `$`, `!`): must become
   the key unchanged and open with the same string → Task 1 `pty_passesPasswordWithSymbols`
3. **Compressing where you cannot write** (right-clicking inside a read-only folder): fails with a clear message and
   leaves no partial file → Task 6 `job_failsCleanlyInReadOnlyDirectory`
4. **Empty folders and 0-byte files**: compress, and verification (file count) passes → Task 6
   `job_archivesEmptyDirectory`
5. **A `name.7z.partial` left over from an earlier failure**: not clobbered; a different temporary name is used →
   Task 2 `partialURL_avoidsExistingPartial`

### Task 6: The compression job (ArchiveJob)

**Files:**
- Create: `Core/Sources/PassArcCore/ArchiveJob.swift`
- Test: `Core/Tests/PassArcCoreTests/ArchiveJobTests.swift` (runs the real 7zz and zstd)

**Interfaces:**
- Consumes: everything from Tasks 1–5
- Produces:
  ```swift
  public enum JobPhase: Equatable, Sendable { case compressing(Double?), verifying }
  public enum ArchiveError: Error, Equatable, Sendable {
    case toolMissing(Tool)        // message: "7zz was not found; run brew install sevenzip in Terminal" (zstd: brew install zstd)
    case failed(String)           // the last 20 lines of the tool's output, with the password replaced by "••••"
    case verificationFailed       // "the new archive failed verification"
    case cancelled
    public var message: String }
  public final class ArchiveJob: @unchecked Sendable {
    public init(request: ArchiveRequest, locate: @escaping (Tool) -> URL? = { ToolLocator.locate($0) })
    public func run(progress: @escaping @Sendable (JobPhase) -> Void) async throws -> URL  // the final output
    public func cancel()
  }
  ```

Order: look up the tool → `FileInventory.scan` → `outputURL` and `partialURL` → compress (7z/ZIP through
`PTYRunner`; tar.zst reads tar's stdout and writes it to zstd's stdin while counting; progress is bytes written /
totalBytes, clamped to 0...1) → `verifying` → verify (7z/ZIP: the `Files: N` in `sevenZipTest` output matches
`fileCount`; tar.zst: `zstdTest` exits 0) → `moveItem` from partial to output. On any failure or stop, delete the
partial file if it exists. `cancel()` stops the running process, and `run` throws `.cancelled`.

### Task 8: The app (dialog, progress, notification)

**Files:**
- Create: `poc/passarc/project.yml`, `App/AppDelegate.swift`, `App/ArchiveWindowController.swift`,
  `App/ArchiveDialogView.swift`, `App/ArchiveDialogModel.swift`, `App/Notifier.swift`, `App/Info.plist`

**Interfaces:**
- Consumes: `DialogState`, `SettingsStore`, `ArchiveURL.parse`, `ArchiveJob`, `ArchiveError.message`
- Produces: the app `PassArc.app` (bundle ID `local.passarc.app`). The `passarc` URL scheme is registered in
  `Info.plist` `CFBundleURLTypes`, with `LSUIElement = YES`.

`project.yml`: target `PassArc` (application, macOS 15, `CODE_SIGN_IDENTITY: "-"`, `ENABLE_APP_SANDBOX: NO`),
depending on the local package `Core`. Task 9 adds the extension target.

Behaviour (as in design §4 and §5):
- `application(_:open:)` calls `ArchiveURL.parse` → one window per call (several can be open). The window is
  centred and in front (`NSApp.activate`).
- Title: one item "📁 Compress <name>", several "📁 Compress N items".
- Format as vertical radios (7z / ZIP / tar.zst), level as horizontal radios (Fast / Normal / Maximum), and the
  "Protect with a password" checkbox. Only while it is checked, show `SecureField`s for Password and Verify, and
  show `passwordMessage` under them.
- Compress is enabled by `canSubmit` and bound to Enter. Cancel is Esc.
- On Compress: `SettingsStore.save`, switch to a progress bar (indeterminate for `compressing(nil)`, "Verifying"
  for `verifying`) and Stop, then `ArchiveJob.run`.
- Success: close the window and post the notification "Created <file name>". Clicking it calls
  `NSWorkspace.shared.activateFileViewerSelecting([url])`.
- Failure: show `ArchiveError.message` and Close in the window. Stop: close quietly.
- Clear the password string from the model when the job is done.
